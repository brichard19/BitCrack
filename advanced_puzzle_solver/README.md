# 🔍 Advanced Bitcoin Puzzle Solver v2.0

## 🎯 Что это такое?

Продвинутый решатель Bitcoin Puzzle с полным функционалом для поиска кошельков с балансами. Включает в себя:

- ✅ **Генерация мнемоник** и проверка кошельков
- ✅ **Валидация адресов** Bitcoin и Ethereum
- ✅ **Проверка балансов** в реальном времени
- ✅ **Многосетевую поддержку** (Bitcoin, Ethereum)
- ✅ **Многопоточность** для максимальной производительности
- ✅ **Автосохранение** результатов и прогресса
- ✅ **Живую статистику** с красивым интерфейсом

## 🚀 Быстрый старт

### 1. Запуск простой командой:
```bash
./run_solver.sh
```

### 2. Или вручную:
```bash
# Активация виртуальной среды
source puzzle_env/bin/activate

# Запуск полнофункционального решателя
python3 puzzle_solver.py

# Или высокопроизводительного
python3 high_performance_solver.py
```

## 🎮 Режимы работы

### 1. 🧮 Полнофункциональный решатель (`puzzle_solver.py`)

**Возможности:**
- Последовательный поиск в диапазоне
- Случайный поиск с ограничением по времени
- Генерация мнемоник
- Проверка балансов в Bitcoin и Ethereum
- Многопоточность
- Автосохранение

**Режимы поиска:**
1. **Последовательный** - перебор в заданном диапазоне
2. **Случайный** - случайная генерация ключей (24 часа)
3. **Мнемоники** - генерация через BIP39 фразы
4. **Смешанный** - комбинация всех методов

### 2. ⚡ Высокопроизводительный решатель (`high_performance_solver.py`)

**Оптимизации:**
- Максимальное использование всех CPU ядер
- Большие батчи для обработки
- Предвычисленные таблицы
- Минимальное логирование
- Кеширование результатов
- Живая статистика в терминале

## 📊 Результаты

Все найденные кошельки сохраняются в файлы:
- `found_wallets.json` - найденные адреса с балансами
- `high_performance_results.json` - результаты HP режима
- `solver_progress.json` - прогресс выполнения
- `puzzle_solver.log` - подробные логи

## 🔍 Что проверяется

### Bitcoin адреса:
- P2PKH (начинающиеся с '1')
- P2SH (начинающиеся с '3') 
- Bech32 (начинающиеся с 'bc1')
- Сжатые и несжатые ключи

### Ethereum адреса:
- Стандартные адреса (0x...)
- Проверка балансов через Etherscan API

### Валидация:
- Проверка чексумм адресов
- Валидация приватных ключей
- Контроль диапазонов Puzzle

## 🌐 Сетевые проверки

### Bitcoin:
- **blockstream.info** - основной API
- **blockcypher.com** - резервный API
- Кеширование результатов
- Обработка rate limits

### Ethereum:
- **etherscan.io** API
- Поддержка API ключей
- Автоматические retry при ошибках

## 💡 Стратегии поиска

### 1. Последовательный поиск
**Плюсы:**
- Полное покрытие диапазона
- Гарантированный результат при достаточном времени

**Минусы:**
- Очень медленно для больших диапазонов

### 2. Случайный поиск
**Плюсы:**
- Быстрое покрытие разных областей
- Возможность раннего нахождения

**Минусы:**
- Может пропустить целевой ключ
- Нет гарантии покрытия

### 3. Мнемонический поиск
**Плюсы:**
- Покрывает всё пространство ключей
- Находит любые кошельки с балансами

**Минусы:**
- Очень низкая вероятность попадания в Puzzle диапазон

## 🐛 Решение проблем

### Ошибки зависимостей:
```bash
# Пересоздание виртуальной среды
rm -rf puzzle_env
python3 -m venv puzzle_env
source puzzle_env/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

### Ошибки сети:
- Проверьте интернет соединение
- Добавьте API ключи в конфигурацию
- Увеличьте интервалы проверки

### Низкая производительность:
- Используйте `high_performance_solver.py`
- Увеличьте размер батчей
- Уменьшите частоту проверок балансов

## 📈 Ожидаемая производительность

### На современном CPU (8 ядер):
- **Генерация ключей**: ~50,000 ключей/сек
- **Проверка адресов**: ~10,000 адресов/сек
- **С проверкой балансов**: ~1,000 адресов/сек

### Вероятности:
- **Puzzle #71**: 1 из 2^71 ≈ 2.36 × 10^21
- **Случайный кошелек**: ~1 из 10^12 активных адресов
